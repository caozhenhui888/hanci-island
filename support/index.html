Support · FAQ

支持与常见问题

这里汇总当前版本的实际操作方式。若问题涉及数据删除、备份或 Apple 授权，请先阅读说明再操作。

支持

韩词屿面向已满14周岁的用户提供本地韩语词汇学习功能。遇到数据删除、备份或设备问题，可按下方步骤处理或联系支持。

先从最常见的问题开始。

以下回答对应当前首发版本的实际使用方式。

为什么韩词屿要求年满14周岁？

韩词屿首发版本仅面向已满14周岁的用户开放，不向未满14周岁的用户提供服务。首次使用时需要确认年龄；选择“我未满14周岁”后，App 会阻止进入正常学习流程。

年龄确认是产品准入自我声明，不收集出生日期、精确年龄、身份证号码、电话号码或监护人身份，也不构成真实身份或年龄验证。韩词屿无法保证识别所有虚假年龄选择。

1. 如何开始学习韩语单词？

首次使用时先完成14周岁年龄声明，并在选择“我已年满14周岁”后进入原有 Onboarding。进入主界面后，在“学习”页确认当前目标词书。你可以使用已有的词书级计划，或点击“调整计划”修改每日新词量或目标学习天数。随后点击学习入口，从今日新词或复习任务开始。

如果你想换一本书，可在“词书”页浏览并加入学习，也可以在“学习”页的当前目标区域切换词书。

2. 如何切换为游客模式？

在“我的”页进入 Apple 账户相关区域，选择“切换为游客模式”。当前版本要求 Apple 身份已绑定且当前不是游客模式时，该操作才会改变使用模式。

切换后仍可继续使用本机学习数据。需要重新使用同一 Apple 身份时，可以再次进行 Apple 登录。

3. 切换为游客模式是否删除学习记录？

不会。切换为游客模式只改变 App 内的当前使用模式，不删除 Apple User Identifier、本地用户标识、学习进度、复习日志、收藏、错词、计划、连胜或 Onboarding 状态。

如果你要永久清除本机身份绑定和个人学习数据，需要使用单独的“删除本机账户及学习数据”操作。

4. 如何删除本机账户及学习数据？

在“我的”页找到“账户与数据”，进入“删除本机账户及学习数据”。页面会显示本机待删除和待保留的数据数量。

点击删除后需要完成两次确认：第一次选择“继续删除”，第二次选择“永久删除”。操作成功后，本机 Apple 身份绑定、个人学习数据、年龄政策确认和设置会被清除，正式内置词书会保留。App 会重新显示14周岁年龄声明，确认后再进入首次使用引导。

建议在永久删除前，先确认是否需要通过“备份与恢复”导出 JSON 备份。

5. 删除后能否通过同一个 Apple ID 恢复？

不能自动恢复。删除后同一 Apple ID 可以再次登录，但会对应删除后的空白本地学习数据，不会找回以前的进度和日志。

只有在删除前主动导出过 JSON 备份，并且该备份仍保存在你的外部位置时，才可能通过“备份与恢复”主动导入。导入前请仔细查看预览和冲突提示。

6. 如何导出 JSON 备份？

进入“我的”，打开“备份与恢复”，先生成备份文件，再点击“保存或分享备份”。随后由 iOS 系统分享界面选择“文件”、iCloud Drive、邮件或其他接收位置。

App 不会自动上传备份。备份可能包含学习历史、自定义内容和本地用户标识，但不包含 Apple User Identifier、姓名、邮箱、Apple Token 或年龄政策确认状态。请妥善保管。

7. 已经分享的备份文件如何处理？

文件交给“文件”、iCloud Drive、邮件或其他 App 后，韩词屿无法再直接删除该副本。请在对应的文件位置、邮件账户或第三方 App 中自行管理。

删除本机账户及学习数据时，App 不会删除你已经保存到外部位置的 JSON 备份。

8. 更换 iPhone 后能否自动同步学习进度？

当前版本不提供 iCloud、CloudKit 或跨设备自动同步。更换设备不会自动迁移学习进度。

如要迁移，需要在旧设备上主动导出 JSON 备份，把文件转移到新设备，再在新设备中使用“选择备份文件”恢复。你也可以通过完整的系统设备备份迁移 App 数据，但该过程由 iOS 和你的备份设置管理。

9. 韩语发音无法播放怎么办？

韩语发音使用 iOS 系统 AVSpeechSynthesizer。请先检查设备媒体音量、系统静音或专注模式设置，并确认系统已提供韩语语音。

可在 iOS“设置”中查看系统语音相关选项，或更新到受支持的 iOS 版本后重试。如果 App 显示“当前设备没有可用的韩语系统语音”，说明系统未提供可用的韩语 voice。

韩词屿不录音，也不使用第三方语音 API。若其他韩语语音 App 同样无法播放，建议优先检查系统语音资源。

未成年人使用说明

韩词屿首发版本仅面向已满14周岁的用户开放。未满14周岁的用户不能通过申请、监护人陪同、游客模式或 Apple 登录进入正常使用流程。

14—17 周岁的用户仍然属于未成年人，满足最低使用年龄不代表与成年人完全等同。用户应在能够理解隐私政策和用户协议的情况下使用，必要时可寻求监护人阅读和协助。

当前 App 不提供专门的未成年人账号、监护人控制台或监护人身份绑定。如用户希望了解、更正或删除本机数据，请通过 caozhenhui888@gmail.com 联系。请求时不要发送 Apple Token、设备密码或其他敏感凭据。
