本协议适用于韩词屿（HANCI ISLAND）iOS App 及其配套本地使用功能。公开运营主体为 曹振晖（个人开发者）。

首发市场为中国大陆。本协议不排除其他地区强制性法律规定赋予用户的法定权利。

2. App 服务说明

韩词屿是一款本地韩语词汇学习 App，提供词书浏览、新词学习、答题反馈、每日目标、词书级学习计划、复习安排、收藏、错词标记、学习统计、自定义词表导入和 JSON 备份恢复等功能。

当前版本没有开发者自有服务器账户、CloudKit 同步、跨设备自动同步、付费订阅、自动续费或退款流程。若未来增加这些功能，应在上线前补充相应条款并更新隐私政策。

功能可用性可能受设备、iOS 版本、系统语音资源、可用存储空间和用户设置影响。App 不承诺所有功能在全部设备或全部地区永久可用。

3. 账户与游客模式

用户可以无需 Apple 登录，以游客模式使用核心学习功能。当前 App 在本机使用一个本地用户标识关联学习记录，不提供多账号切换或云端账号迁移。

“切换为游客模式”仅改变当前 App 使用模式，保留本机 Apple 身份绑定和全部学习数据。该操作不等于删除账户，也不撤销 Apple 系统授权。

“删除本机账户及学习数据”是独立的永久删除操作。该操作会清除当前本机 Apple 身份绑定、学习进度、复习日志、收藏、错词、计划、自定义内容和相关设置，并保留 App 内置词书。删除后同一 Apple ID 再次登录不会自动恢复以前的数据。

4. 用户资格与未成年人使用

韩词屿首发版本仅面向已满14周岁的用户开放，不向未满14周岁的用户提供服务。未满14周岁的用户不能通过申请、监护人陪同、游客模式或 Apple 登录使用本服务。

首次使用 App 时，用户需要选择“我已年满14周岁”或“我未满14周岁”。选择未满14周岁时，App 会阻止进入 Onboarding、主界面和学习功能。选择已满14周岁时，App 只在本机保存当前年龄政策确认版本 v1。

年龄声明是产品准入自我声明，不收集出生日期、精确年龄、身份证号码、电话号码或监护人身份，也不构成真实身份或年龄验证。用户应如实作出声明，App 无法保证识别所有虚假年龄选择。

14—17 周岁的用户仍然属于未成年人。满足最低使用年龄不表示其与成年人完全等同，也不排除适用未成年人保护和个人信息保护相关要求。用户应在能够理解本协议和 隐私政策未成年人部分的情况下使用，必要时可寻求监护人阅读和协助。

当前首发版本不提供专门的未成年人账号、监护人控制台或监护人身份绑定，也不向未满14周岁用户开放。本协议不声称已经取得统一监护人同意，亦不排除未成年人依法享有的权利。

如14—17周岁用户对本协议或个人信息处理有疑问，可由本人或依法有权代为处理的人员通过本协议所列邮箱联系运营主体。不得利用本协议排除或限制未成年人依法享有的权利。

5. Apple 登录与本地身份绑定

Apple 登录是可选功能。当前版本仅请求完成本地身份绑定所需的稳定 Apple User Identifier，不请求姓名或邮箱资料。身份绑定信息保存在本机，不由开发者自有服务器接收。

Apple 登录、系统授权状态和 Apple 账户由 Apple 独立提供并管理。韩词屿不代表 Apple，也不能删除用户的 Apple 账户或替用户撤销 Apple 系统授权。

用户应使用自己有权使用的 Apple 账户。为避免不同身份误接管同一份本机历史，当本机已绑定其他 Apple User Identifier 时，App 可以拒绝不同 Apple 身份的接管。

6. 学习数据与备份

学习记录默认保存在用户设备本地。用户应理解，卸载 App、清除 App 数据、删除本机账户、设备故障、系统恢复或用户主动恢复旧设备备份，都可能影响当前本地学习记录。

用户可主动生成 JSON 备份，并通过 iOS 系统分享界面保存到“文件”、iCloud Drive、邮件或其他 App。App 不会自动上传备份；年龄政策确认状态不包含在 JSON 备份中。文件交给其他位置后，其保存、访问和删除由用户及接收方管理。

用户应妥善保管备份文件。备份可能包含学习历史、自定义内容和本地用户标识，不应随意发送给不可信的个人或服务。
