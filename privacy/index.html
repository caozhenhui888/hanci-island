1. 运营者与适用范围

产品名称：韩词屿（HANCI ISLAND）。
产品类型：韩语词汇学习 iOS App。
个人信息处理者／公开运营主体（最终法律表述待审核）：曹振晖（个人开发者）。
隐私联系邮箱：caozhenhui888@gmail.com

本政策拟适用于韩词屿 iOS App 及本官网中与数据处理有关的页面。首发市场为中国大陆。若未来向其他地区提供产品，相关地区的强制性法律规定仍可能适用，本草稿不作排除性承诺。

个人信息处理者的最终法律表述、是否需要披露更多法定主体信息以及适用的消费者和个人信息保护要求仍需法律审核。

开发者决定不在公开官网展示个人联系地址。本页不填写住所、注册地址或推测地址；如后续法律审核确认必须公开其他联系信息，将另行补充真实信息。

韩词屿首发版本仅面向已满14周岁的用户开放，不向未满14周岁的用户提供服务。首次使用 App 时，用户需要确认是否已满14周岁。

用户选择“我未满14周岁”时，App 会阻止进入首次使用引导、学习界面、游客模式和 Apple 登录。选择“我已年满14周岁”后，App 会记录当前年龄政策版本 v1，再进入原有 Onboarding 或主界面。

App 只在本机保存年龄政策的确认版本，不收集或保存出生日期、精确年龄、身份证号码、电话号码或监护人身份。该确认状态不进入用户主动导出的 JSON 备份；删除本机账户及学习数据时会被清除。重新安装、清除本机数据或恢复历史设备备份后，可能需要重新确认。

年龄确认属于产品准入自我声明，不构成真实身份或年龄验证，不能保证识别所有虚假年龄选择。韩词屿不是专门的儿童教育产品，当前也不提供未满14周岁儿童模式。

当前版本不提供开发者自有服务器账户系统，也不提供 CloudKit、跨设备自动同步或其他云端同步功能。

2. App 在本机保存的数据

为提供背词、学习计划和复习功能，韩词屿会在用户设备本地保存以下信息：

数据类别 示例 保存方式
学习记录 学习进度、复习阶段、答题记录、下一次复习日期 SwiftData App 容器
个人学习组织 收藏、错词或“需要加强”状态、加入学习的词书 SwiftData App 容器
学习设置 每日目标、词书计划、当前选中文书、连续学习记录 App 的 UserDefaults
用户导入内容 用户主动导入的自定义词书、词条和来源信息 SwiftData App 容器
界面状态 首次使用引导是否完成、本地用户标识、已接受的年龄政策版本 App 的 UserDefaults

学习统计通常由本地学习记录实时计算，不另行上传到开发者服务器。当前版本不使用 CloudKit，也不会自动把学习记录同步到其他设备。

3. 可选的 Apple 登录

用户无需登录即可使用当前版本的核心背词功能。Apple 登录是可选功能，用于在本机建立身份绑定。

当前源码中的 Apple 登录请求不申请姓名或邮箱资料范围，不读取或保存 Apple 登录姓名、真实或隐藏邮箱、身份令牌（identityToken）、授权码（authorizationCode）或刷新令牌（refreshToken）。App 仅接收并保存 Apple 返回的稳定 User Identifier，以及绑定状态、授权检查时间和本地用户标识。

Apple 登录的认证界面和认证过程由 Apple 系统服务提供。韩词屿没有接收这些认证信息的开发者服务器。Apple 系统自身如何处理认证过程，适用 Apple 的相关条款与隐私政策。

“切换为游客模式”只改变 App 内的使用模式，不删除 Apple User Identifier，也不删除学习记录。若用户选择“删除本机账户及学习数据”，App 会清除本地保存的 Apple 身份绑定和对应的个人学习数据。

4. 网络请求、第三方 SDK 与追踪

根据当前源码与依赖审计，韩词屿没有开发者自有后端、URLSession 网络客户端或硬编码开发者 API 地址，也未发现自动向开发者服务器上传学习数据的代码。

当前版本没有接入广告、应用分析、归因、跨 App 追踪或第三方崩溃收集 SDK，不使用广告标识符进行追踪。Apple 登录、iOS 系统分享、系统语音和设备备份属于 Apple 提供的系统能力，不由开发者服务器接管。

App 使用本地 ZIPFoundation 代码处理 ZIP 或 XLSX 文件。ZIPFoundation 用于设备本地文件处理，不是数据收集、广告或分析服务。

App 可能在 Apple 系统统一日志（OSLog）中记录本地错误或性能耗时，用于开发和故障排查。当前源码未发现把开发者服务器日志上传作为业务流程；系统诊断日志的实际管理仍受 iOS 设置与 Apple 平台机制影响。

5. 系统语音与音频

韩语发音使用 iOS 系统框架 AVSpeechSynthesizer 进行语音合成。App 不会把要朗读的韩语文本发送到开发者自有服务器，也没有接入第三方语音 API。

韩词屿不录制音频，不读取麦克风数据，当前版本也未申请麦克风权限。系统语音是否使用已下载的本地语音、何时需要系统下载资源，由 iOS 和用户设备状态管理。

答题和完成反馈音效来自 App 内置的本地音频资源，不使用远程音频服务。

6. 用户主动备份、导出与分享

用户可以在 App 内主动生成 JSON 备份。备份可包含学习进度、复习日志、收藏与错词状态、学习目标、词书计划、连续学习状态、自定义词书和关联信息，以及本地用户标识。备份不包含 Apple User Identifier、姓名、邮箱、Apple Token、授权码或年龄政策确认版本。

App 不会自动上传备份。用户点击“保存或分享备份”后，iOS 系统分享界面会让用户自行选择接收位置或 App，例如“文件”、iCloud Drive、邮件或其他第三方 App。

文件交给用户选择的接收方后，韩词屿不能控制该副本，也无法保证删除已经保存到外部位置、发送给他人或由第三方 App 保存的文件。接收方如何处理数据，适用接收方自己的条款与隐私政策。

恢复备份时，App 会先显示预览和冲突检查。只有在用户可以确认无阻塞冲突时才执行恢复。用户主动选择使用备份中的目标和词书计划时，App 可能用备份内容替换对应本地设置。

7. 删除本机账户及学习数据

韩词屿在“我的”页提供“删除本机账户及学习数据”入口。该操作需要两次确认，完成时会：

  • 删除本机保存的 Apple 身份绑定和 Apple User Identifier；
  • 删除当前本地用户的学习进度、复习日志、收藏、错词状态和学习词书关系；
  • 删除用户导入的自定义词书、词条、关联和不再被保留内容引用的用户来源；
  • 重置每日目标、词书计划、当前选中文书、连续学习状态和个人界面设置；
  • 清除本机保存的年龄政策确认版本；
  • 重置首次使用引导；
  • 保留 App 正式内置词书及其必要内容记录。

删除完成后，App 会先重新显示14周岁年龄声明。再次确认已满14周岁并通过 Onboarding 后，App 进入空白游客状态。同一 Apple ID 以后重新登录时，只会对应删除后的空白本地学习数据，不会自动恢复删除前记录。用户主动保存到外部位置的 JSON 备份仍可由用户自行重新导入。

删除本机身份绑定不等于撤销 Apple 系统授权。当前版本没有服务器端账号系统、Token Revocation API 或服务器端数据删除流程。Apple 账户仍可能保留该 App 的系统授权记录；如需停止 Apple 授权，请由用户在 Apple 系统设置中自行管理。

App 不能删除用户已经导出到外部位置的文件，也不能删除历史 iOS 或 iCloud 设备备份。

8. iOS 与 iCloud 设备备份

韩词屿当前不使用 CloudKit，也不提供跨设备同步。不过，若用户启用了 iOS 设备备份或 iCloud 备份，系统备份可能包含 App 容器或 UserDefaults 中的本地数据。

这类备份由 Apple 系统及用户设置管理，不是韩词屿的云端同步服务。App 内删除当前数据不会自动删除已经形成的历史设备备份，也不能保证从旧备份恢复设备后不会重新出现旧数据。

9. 数据安全

App 通过 iOS App 沙盒和系统提供的本地数据保护机制保存数据，并仅在当前功能需要的范围内访问用户学习记录。删除流程采用先验证、后精确删除、再执行完整性检查的方式，避免通过删除整个数据库实现用户删除。

任何电子存储都不能保证绝对安全。用户也应妥善保管设备、系统账户、导出的 JSON 备份和分享目标。

10. 用户选择与权利

当前版本允许用户不登录使用核心学习功能，允许切换为游客模式，并提供本机账户及学习数据删除入口。Apple 登录授权状态由 Apple 系统管理。

关于访问、更正、复制、删除、撤回同意或其他个人信息权利请求，可以通过 caozhenhui888@gmail.com 联系公开运营主体曹振晖。具体请求流程、身份核验方式和适用法律下的响应期限仍需法律审核。

11. 未成年人

韩词屿首发版本仅面向已满14周岁的用户开放。未满14周岁的用户不能通过申请、监护人陪同、游客模式或 Apple 登录进入正常使用流程。

14—17 周岁的用户仍然属于未成年人。满足最低使用年龄不代表其与成年人完全等同，也不代表可以不受未成年人保护和个人信息保护相关要求约束。韩词屿不会因该年龄段的用户使用基础学习功能而额外要求其提交身份证、学校、电话或其他敏感身份材料。

当前 App 不提供专门的未成年人账号、监护人控制台或监护人身份绑定。Apple 登录为可选功能；如用户主动登录，本机 Apple User Identifier 可能与本地学习记录形成关联。14—17 周岁的用户应在能够理解本政策和用户协议的情况下使用，必要时可寻求监护人阅读和协助。

当前首发版本不向未满14周岁用户开放，因此不提供儿童账号、监护人同意流程或儿童个人信息专门处理界面。未来若开放未满14周岁用户使用，将另行设计儿童模式、监护人同意机制和专门的儿童个人信息保护规则；在这些机制完成前，不会通过网页文案将未满14周岁用户描述为可以使用。

12. 政策更新

如果 App 新增服务器、跨设备同步、分析、广告、付费、推送或其他会改变数据处理方式的功能，本政策应在上线前更新。正式发布时应标明版本号、更新日期和生效日期，并在适当位置提供历史版本或变更说明。
